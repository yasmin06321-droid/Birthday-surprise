# Birthday Surprise Website 🎂💖

A responsive birthday greeting website with:
- Animated birthday surprise
- Sweet birthday messages
- Photo gallery
- Confetti animation
- Mobile-friendly design

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will give you the website link.

## Personalize
Open `index.html` and replace "Happy Birthday Beautiful!" or the messages with your own words.
